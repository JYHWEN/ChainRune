# ChainRune

Translates machine code into readable assembly code for embedded systems developers and hobbyists.

ChainRune is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Translates machine code into readable
- assembly code for embedded systems
- developers and hobbyists

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainRune.git`
2. `cd ChainRune`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
